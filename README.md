# StudyMate AI — Intelligent Student Academic Assistant

StudyMate AI is an AI-powered academic assistant designed to help students study smarter and manage their academic tasks efficiently.

## Features
- AI-powered academic Q&A
- Study Planner
- Summarize Study Material
- Attendance Analyzer
- Report Generator

## Technology Stack
- Python / Web technologies (as used in the project)
- Google Gemini API

## Project Goal
To make learning, study planning, and academic task management easier for students.

## Status
Under development.
